# Background Image Needed

Please place your background image in this directory:

## File Required:
**or.png** - Background image for videos

## Specifications:
- **Aspect Ratio**: 9:16 (vertical, like 1080x1920)
- **Format**: PNG or JPG
- **Name**: Must be exactly `or.png`
- **Content**: Any visually appealing background design

## Current Status:
⚠️ **Background image not found!**

The video generator will use a black background instead.

## To fix:
1. Create or download a 9:16 background image
2. Name it `or.png`
3. Place it in this folder (`assets/images/`)
4. Refresh the video generator page

## Quick Create:
You can create one using:
- Canva (free, use "Instagram Story" template - 1080x1920)
- Photoshop/GIMP
- Any online image editor

Make it colorful and eye-catching for "Would You Rather" videos!
