# Engagement Images

This folder contains images for engagement prompts.

## Required Images:

1. **comment.png** - Used for "I love God" engagement prompt (top option)
2. **reject.png** - Used for "Reject the offer" engagement prompt (bottom option)
3. **marry.png** - Used for "Marry the 3rd person" engagement prompt

## Image Specifications:
- Format: PNG
- Recommended size: 400x400px (square)
- Transparent background preferred

## Usage:
These images are displayed at the end of videos as engagement hooks to increase viewer interaction.
